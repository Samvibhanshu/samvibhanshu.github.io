# samvibhanshu.github.io

My portfolio: https://samvibhanshu.github.io

Plain HTML, CSS and a little JavaScript, with no build step, so GitHub Pages serves the files as they are.

| Page | File |
|---|---|
| Home | `index.html` |
| About (education, skills, certifications) | `about.html` |
| Projects, with filter and search | `projects/index.html` |
| One page per project | `projects/<name>.html` |
| Research (patent applications, papers) | `research.html` |
| Experience | `experience.html` |
| Resume (web version; PDF in `Samridhi_Resume.pdf`) | `resume.html` |

Shared by every page: `style.css` (light and dark themes), `site.js` (theme switch, project filter). Figures are in `assets/`.
To preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
