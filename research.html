How I turn a disclosure into code

Measure the claim

The wildfire disclosure projected 90–95% accuracy. The code measures 58% in cross-validation, and the page reports both.

Beat a real baseline

Opinion lineage is compared with a deduplication baseline tuned on the answer. Against that one it is comparable, not better, and the README says so.

No look-ahead

Trust-decay forecasting uses chronological, purged splits, and a test rebuilds the graph truncated at each day to prove no future event leaks in.
