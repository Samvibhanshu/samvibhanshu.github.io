Notes app

Create, edit, search, copy and delete notes, saved in the browser, with a store that cannot be crashed by bad saved data.

  • Web
  • 13 tests

What it does

  • Create and edit from one form: opening a note for editing switches the button from Create to Update.
  • Search notes by title as you type.
  • View a note on its own page and copy its content in one click; deleting shows a toast.
  • Persistence: the Redux store starts from localStorage and writes back only when the notes actually change.

Design notes

  • Reducers are pure. Saving to storage and showing toasts used to happen inside the reducers. Redux requires reducers to be free of side effects, so saving is now a store subscriber and toasts come from the components. That also made the reducers testable on their own.
  • Defensive views. Corrupted or blocked storage cannot crash the app: unreadable data is ignored and the app keeps working in memory. Opening a deleted note’s link shows a message instead of crashing.
  • Deployment. A rewrite rule sends every path to index.html, so a link to a single note keeps working on refresh instead of returning 404.
  • Tests (Vitest) cover the reducers, safe loading, persistence and the note page.
