Systems in Java

  • agentic-bug-repair

    Takes a Java repository with failing tests and tries to fix it: indexes the code as a call graph, ranks where the bug probably is, tries small patches in an isolated sandbox, and only proposes a pull request whose diff passes every test on a clean checkout. Live dashboard and GitHub webhook.

    Java 17, JDK compiler API, no dependencies

    148 tests Repairs 4 of 20 seeded bugs with no model; the README explains why the rest fail

  • order-service

    E-commerce order backend: place, pay, ship and cancel over a JSON HTTP API. It never oversells under concurrency, never charges twice when a payment is retried, and only allows legal state changes.

    Java 17, java.util.concurrent, JDK HTTP server

    30 tests 64 threads race for the last 50 units: exactly 50 orders succeed, every time

  • mini-sqs

    A message queue with Amazon SQS semantics: visibility timeouts, receipt handles, dead-letter queues and redrive, FIFO groups with deduplication, long polling, and a worker pool with exponential backoff.

    Java 17, no dependencies

    26 tests 600 random operation sequences; no message is ever lost, duplicated or delivered out of FIFO order

  • route-planner

    Delivery routing on a city road network: BFS, Dijkstra, A* and bidirectional Dijkstra, then a van's round through many stops with Held–Karp (exact) and nearest neighbour plus 2-opt.

    Java 17, no dependencies

    19 tests Checked against Floyd–Warshall and brute force; A* settles 2.2× fewer nodes than Dijkstra

Research prototypes

  • Opinion lineage

    Measures what people actually think on social media by tracking which posts copy, paraphrase or AI-rewrite which. When a source turns out to be fake, only its descendants are re-weighted, with no model re-runs. A question-answering layer on top cites independent posts.

    Python, NumPy, scikit-learn, networkx

    27 tests With 40% coordinated content, error 0.007 vs 0.038 for a raw count (simulated stream)

  • Trust decay prediction

    Predicts which IT assets are losing trust from audit events in a temporal knowledge graph, and ranks them for audit with explanations. Dashboard and JSON API.

    Python, scikit-learn, networkx, Flask

    68 tests Auditing the top 10% finds high or critical decay 47% of the time, vs 31% at random (simulated)

  • Wildfire risk prediction

    Wildfire-risk ensemble on the UCI Forest Fires data, with resource orchestration and a live dashboard. The models are constrained so hotter, drier weather can never lower the predicted risk.

    Python, scikit-learn, Flask, SQLite

    71 tests Measured accuracy reported next to the projected figures
